# Tablero XR · Defender for Cloud

Mapa holográfico 3D (WebXR · Meta Quest 3) de un tenant de Microsoft Azure con el
estado de seguridad de Microsoft Defender for Cloud. Prototipo con datos de ejemplo;
la conexión a un tenant real es de solo lectura (Entra ID / MSAL).
